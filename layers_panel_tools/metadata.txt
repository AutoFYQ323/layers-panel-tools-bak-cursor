about=Layers Panel Tools adds buttons to the toolbar of the existing Layers panel. After installation there is no main-window toolbar icon: every button, and the Layers Panel Tools settings button at the end of the same toolbar, sits on the Layers panel itself. Buttons show an icon only; the name appears on hover and can be renamed.
    On by default: labels (all or selected layers), batch select (zoom to fit, by type or state, never touching basemaps), layer manager (show/labels switches, opacity, style copy/paste, jump to symbology, fields, properties), edit log (roll back operations one by one or by layer, in memory), batch export (point/line/polygon layers to a folder, or several layers into one file when the format allows it; a dialog names the result. For CSV, merge writes a same-named Excel workbook with one sheet per layer unless “one table” is checked, which keeps every field and lists a shared field name only once), polygon select (select, copy, move, or delete features of many layers inside a drawn polygon), feature counts beside layer names, layer visibility schemes (remember which layers and categories are on, per project, with several schemes), basemap presets, solo (show only the selected layers, click again to restore), flash locate (blink layer switches or flash features, adjustable interval), layer actions (clear every feature, start or finish editing, copy a layer with or without features), line marks (start, end, and length in meters on the map, nothing written back), and export by class (one file per legend class or per field value, ESRI Shapefile by default).
    Off by default, one click away in Layers Panel Tools settings: organize (sort, group, layer CSV, snapshots), repair data sources, find layer (name, field, or value search with wildcards), show/hide all layers (basemaps untouched), move layers, opacity slider, copy/paste style, batch rename, copy layer files with sidecars, layer color tags, scale check, and render check.
    Shortcuts: every button — and every function inside a multi-function button — can get its own keyboard shortcut and a custom title. Shortcuts respond only while the QGIS main window has focus, never system-wide. Conflicts are checked while you type: a shortcut already used by another function or by QGIS itself is refused, and its holder is named.
    The layer right-click menu can be reordered, renamed, and hidden. Plugin tools that act on the current layer can be added there, including layer manager, polygon select, visibility schemes, basemap presets, and export by class. Tools QGIS already provides are not offered. A custom name is listed as Original(custom) and the menu itself shows only the custom name. A toolbar title for the same button stays in step. Reset on that page restores only the right-click menu.
    The interface is available in 中文, English, Español, Français, and العربية. The first launch follows the QGIS locale, then the system locale, and the choice is remembered. Arabic lays out plugin windows from right to left. Settings, button order, rows, custom titles, basemap presets, and visibility schemes are stored on this machine and apply to every project; visibility snapshots and layer color tags are stored in the project file. Bulk visibility actions never touch basemap layers.
    Requirements: QGIS 3.28 through 4.99 (Qt 5 and Qt 6). No extra Python packages. Local files only; no binaries, no external services.

    Batch export reports the folder or file when it finishes. For CSV, merge adds a second box, off by default and not remembered: one sheet per layer, written as a same-named Excel workbook because CSV cannot hold sheets; when checked, one CSV table. A field name shared by several layers appears once, and no layer’s fields are dropped.
    Export by class writes one file per legend class, or one file per distinct field value. A classified layer starts from the legend; an ordinary layer starts from a field. Split by field, which added subset layers inside the project, is removed.
    The layer right-click page can also add layer manager, polygon select, visibility schemes, basemap presets, and export by class. A custom name is listed as Original(custom) and shown alone on the menu. The same button’s toolbar title stays in step. Reset on that page restores only the right-click menu.
    Merge export writes several layers into one file when the format can hold them: GeoPackage, SQLite, KML, GML, Excel, ODS, and DXF. Checking merge asks for a file path instead of a folder. CSV cannot keep separate layers in one file. DXF still drops most attributes and says so.
    The layer right-click menu can be reordered, renamed, and hidden. A dropdown adds only plugin tools that act on the current layer. Labels, feature count, style copy, move, batch rename, and line marks are left out because QGIS already has them.
    New tools, on by default: layer actions (clear features, start editing, save and close, copy a layer or an empty copy), line marks (start, end, and length in meters, nothing written to the layer), and export by class. Export by class uses one layer at a time, shown in a dropdown with the feature count. A classified layer is bold red and starts from the legend; an ordinary layer starts from a field. The format defaults to ESRI Shapefile. Start editing and save-and-close do not pop up when they succeed.
    The settings button comes back if the Layers panel toolbar appears late. Turning the plugin off and on in the same QGIS session no longer reapplies a saved visibility scheme.
